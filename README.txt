Prize allocation:

- 5 x ₹50
- 5 x ₹30

- 6 x ₹10
- 3 x Better Luck Next Time
Total: 30 QR codes

DEPLOYMENT:
Deploy this whole project using Netlify continuous deployment from a Git repository
or the Netlify CLI. Do not upload only the site folder: the netlify/functions folder
and package.json are required for one-time QR claims to work.

PRINTING:
The print-only/qr-print.html file contains the 30 unique QR links. Open this file
on your computer in a browser while connected to the internet, then click Print QR
Codes. It is intentionally outside the published "site" folder so the list of
unused QR tokens is not exposed as a public page.

The QR links are set to:
https://bejewelled-manatee-bf86c1.netlify.app

If your final production domain changes, update the base URL in
print-only/qr-print.html before printing.

Each QR code can be claimed once through a Netlify Function and Netlify Blobs.
Do not publish the print-only folder.
